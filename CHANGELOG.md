= Control de Cambios =
Todos los cambios NOTABLES de los scripts publicados quedan documentados en este archivo.

Cada versión de un script es una sección con el código del script, su versión (`W.X.Y.Z`) y la fecha en formato ISO 8601 (`YYYY-MM-DD`). La más nueva va arriba. Qué significa cada cifra: [README](README.md#versiones).

Formato: Explicit Changelog.

## Cómo se escribe

```text
== PRENN W.X.Y.Z - YYYY-MM-DD ==

 * KEYWORD
 * Verbo + cambio, en una línea

= Archivos revisados =
-----------------------
archivo.pine
user-guide.md
```

| Palabra clave | Cuándo se usa |
|---|---|
| `ADDITIONS` | Algo nuevo con entidad propia: una señal, un ajuste, una alerta, un apartado de guía |
| `ENHANCEMENTS` | Más sobre algo que ya existía |
| `CORRECTIONS` | Un error corregido |
| `UPDATE` | Un dato, una cifra o una referencia actualizados |
| `REMOVED` | Algo eliminado; se marca `BREAKING CHANGE` si quien usaba el script lo va a notar |
| `DEPRECATED` | Se mantiene por ahora, pero se eliminará |
| `RESTRUCTURED` | Reorganizado sin cambiar lo que hace |

Cada cambio va en una línea y bajo una sola palabra clave.
